**版本:** 5.0
**狀態:** 趨於完美

## 1. 導言：您的萬能系統

歡迎來到 JunAiKey 的全新紀元。

本系統運行於 **量子聖典架構 (Quantum Codex Architecture)** 之上，這是一個多層級的設計，旨在確保安全、可擴展性與智能化運作。它的核心使命是統一您的數位世界，自動化您的工作流程，並將您的數據轉化為可執行的知識。

本手冊是您理解並駕馭 JunAiKey 全部力量的指南。

## 2. 核心架構：五層同心圓模型

您的 JunAiKey 實例建立在五個同心圓層級之上，每個層級都有明確的職責。理解此結構有助於您掌握整個系統。

-   **第 5 層：邊界層 (外部)**
    -   **作用：** 保護並監控整個系統。
    -   **您的互動：** 此層級在後台靜默運作以保護您的數據。其效果體現在系統的整體穩定性與安全性上。`ErrorBoundary` 是此層級的一個可見部分。

-   **第 4 層：接口層**
    -   **作用：** 管理與您（使用者）的所有互動。
    -   **您的互動：** 這是您所見的整個 UI——頁面、按鈕、主題、以及由 AI 生成的詞彙。**主題引擎** 和 **知識對話 (Oracle)** 是此層的關鍵組件。

-   **第 3 層：服務層**
    -   **作用：** 提供所有核心功能作為服務。
    -   **您的互動：** 當您使用 `知識對話`、生成內容或瀏覽 `API 庫` 時，您正在使用此層級的服務。**智庫中樞 (記憶金庫)** 也位於此處。

-   **第 2 層：控制層**
    -   **作用：** 作為「大腦」，控制工作流程與程序。
    -   **您的互動：** 當您在 `全能流程 (OmniFlow)` 中建立規則或在 `全能代理 (OmniAgents)` 中管理代理時，您正在配置控制層。它決定了運行哪些任務以及何時運行。

-   **第 1 層：核心層 (心臟)**
    -   **作用：** 系統的根本本質與進化引擎。
    -   **您的互動：** 您可以透過 `AI 核心終端 (Sanctum)` 直接與此層級互動，以執行診斷命令。此層級負責系統隨時間自我完善的能力。

您可以在應用程式的 **OMC 架構** 頁面查看此架構的可視化表示。

## 3. 入門指南 (Beginner's Guide)

### 3.1 探索您的系統
-   **萬能矩陣 (OmniMatrix)**: 這是您的主導航頁面，展示了系統的 12 個核心維度。從這裡開始探索所有功能。
-   **全能日誌 (OmniLog)**: 您的儀表板，提供所有系統活動和關鍵指標的實時概覽。

### 3.2 第一次對話
-   前往 **知識對話 (Oracle)** 頁面。
-   向 Oracle 提出任何問題，它可以利用 Google 搜索來回答關於最新事件的問題。
-   您的對話將被存儲在 **記憶金庫 (Memory Vault)** 中，為未來的互動提供上下文。

### 3.3 創建您的第一個自動化規則
-   前往 **全能流程 (OmniFlow)**。
-   點擊「創建新規則」。
-   使用「AI 輔助生成」來描述一個簡單的規則，例如：「如果代理的準確率低於 80%，就通知我。」
-   儲存並啟用規則。現在，系統將會自動為您監控代理的表現。

## 4. 進階指南 (Advanced Guide)

### 4.1 核心理念：四大基石
我們的設計哲學基於四個相互支撐的基石，確保系統在各個維度都達到卓越：

| 基石 | 英文 | 核心理念 |
| :--- | :--- | :--- |
| **簡單** | Simplicity | **直觀易用，降低門檻**：將複雜的功能簡單化呈現。 |
| **快速** | Speed | **即時響應，拒絕等待**：確保流暢的操作和快速的 AI 響應。 |
| **實用** | Practicality | **解決真問題，創造真價值**：專注於真實業務場景。 |
| **效能** | Performance | **穩定可靠，高效運行**：資源利用率最大化，並持續自我優化。 |

### 4.2 與 AI 核心互動
-   前往 **AI 核心終端 (Sanctum)**。
-   嘗試輸入 `/core-analyze` 命令。
-   AI 核心將對系統自身的健康狀況、架構和潛在改進點進行全面分析，並以技術報告的形式呈現給您。

### 4.3 擴展系統
-   **API 庫**: 探索系統的 API，了解如何將外部數據或服務整合進 JunAiKey。
-   **自主代理 (Autonomous Agents)**: 啟動背景代理，如「守律者」，來自動維護系統的程式碼品質。

## 5. 附錄：系統規格

-   **數據持久性**: 您所有的數據（規則、記憶、自定義頁面、主題等）都存儲在您瀏覽器的 `localStorage` 中。清除此存儲將會將平台重置為初始狀態。
-   **API 需求**: 平台的智能依賴於與 Google Gemini API 的連接，這需要在環境中設置有效的 API 金鑰。
